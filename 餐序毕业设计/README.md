## 方案主线

1. **加餐联动**：临时加餐可计入每日计划，并清楚显示后续份量变化。
2. **剩粮反馈**：根据稳定后的碗内余粮，按预设规则补粮或暂停提醒。
3. **粮路易拆洗**：关粮后拆出储粮盒、分粮组件与短粮道，电子件保留在干区。
